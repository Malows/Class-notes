# Spec Delta

## REMOVED Requirements

### Requirement: Global Design System

**Reason**: The sketch visual language is retired; tokens and theme behavior are replaced by the editorial Academic Notebook system.

**Migration**: Use the `academic-design-system` capability: editorial visual language and theme modes.

### Requirement: Atomic UI Components

**Reason**: The sketch-styled Card, Button and Badge primitives are replaced by the editorial component set.

**Migration**: Rebuild the primitives on the editorial tokens and component conventions; see `academic-design-system`.

### Requirement: Page Header

**Reason**: The behavior survives, but under the editorial design system rather than the sketch system.

**Migration**: Use the Page Header requirement in `academic-design-system`.

### Requirement: List Row Actions

**Reason**: The behavior survives, but under the editorial design system rather than the sketch system.

**Migration**: Use the List Row Actions requirement in `academic-design-system`.

### Requirement: Link Treatment

**Reason**: The behavior survives with the editorial link treatment instead of the sketch link treatment.

**Migration**: Use the Link Treatment requirement in `academic-design-system`.

### Requirement: Empty States

**Reason**: The behavior survives, but rendered with the editorial component set.

**Migration**: Use the Empty States requirement in `academic-design-system`.

### Requirement: Touch Targets

**Reason**: The behavior survives unchanged as part of the component conventions.

**Migration**: Use the Touch Targets requirement in `academic-design-system`.

### Requirement: Localized Feedback

**Reason**: The behavior survives unchanged as part of the component conventions.

**Migration**: Use the Localized Feedback requirement in `academic-design-system`.

### Requirement: Content Measure

**Reason**: The readable measure changes from the sketch container to the editorial maximum width.

**Migration**: Use the Content Measure requirement in `academic-design-system`.
